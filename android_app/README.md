# SpicyChat QOL Android App

Flutter WebView port of SpicyChat QOL. This build bundles the mobile-compatible content scripts from extension build **0.1.8.21**.

Backup tools in the floating native menu support:

- Import backup JSON file
- Paste backup JSON text
- Export backup JSON file
- Copy backup JSON text

The Android system file picker is used, so the app does not need broad storage permission.

Build from the combined source root with `build_android.bat` or `build_android.ps1`. See the root `README.md` and `ANDROID_STUDIO_SETUP_WINDOWS.md`.
